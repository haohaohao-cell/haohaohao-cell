### Selected projects

- **[agent-silent-failure](https://github.com/haohaohao-cell/agent-silent-failure)** — Fault-injection harness for tool-using agents. One read-only status tool took human hand-offs from 90% to 0%; a stronger model and a different framework changed nothing.
- **[pythia-pl](https://github.com/haohaohao-cell/pythia-pl)** — Probabilistic Premier League forecasts, benchmarked against the de-vigged closing line. 3,044-match walk-forward backtest; the model loses by 0.021 log loss and the repo says so.
- **[spectrumfog](https://github.com/haohaohao-cell/spectrumfog)** — Partially observable spectrum-electromagnetic simulation: physics core, deterministic replay, and a web coverage explorer.
- **[goat-atlas](https://github.com/haohaohao-cell/goat-atlas)** — An open, source-backed career atlas for Cristiano Ronaldo — and eventually every footballer.
